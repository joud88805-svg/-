فزعة — نسخة أركيد تجريبية

طريقة النشر:
1) ارفع index.html إلى مستودع GitHub الذي يستخدم GitHub Pages، واستبدل النسخة السابقة.
2) من Settings > Pages تأكد أن المصدر main والمجلد /(root).
3) افتح رابط الموقع بعد اكتمال النشر.

مميزات النسخة:
- تحدي ضغط سريع لمدة 60 ثانية.
- نقاط وسلسلة ضربات ومكافآت.
- متجر أهداف يمكن فتحها بالريالات داخل اللعبة.
- لوحة نتائج يومية وعامة محفوظة محليًا في المتصفح.

مهم:
- لوحة النتائج في هذه النسخة محلية على نفس الجهاز والمتصفح فقط، وليست لوحة مشتركة على الإنترنت.
- إذا أردت لوحة متصدرين مشتركة، يلزم إعداد قاعدة بيانات مثل Supabase وربطها بشكل آمن.
- هذه لعبة أصلية مستوحاة من أسلوب ألعاب النقر والتحدي، وليست نسخة من الموقع المرجعي.
